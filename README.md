# Portfolio — Andreas Tri Dewa Putra

Static single-page portfolio (Tailwind via CDN, no build step). Open `index.html` in a browser.

Design system: **Signal / Noise** — monochrome neo-brutalist layout, light/dark themes, EN/ID language switch.
See `DESIGN.md` for tokens, components, motion and how to edit translations.

## Structure

```
index.html      # the portfolio page (markup, styles, scripts, EN/ID dictionary)
DESIGN.md       # design tokens / style spec ("Signal / Noise")
assets/         # images (andreas.webp portrait)
certificates/   # course, language & committee certificates (PDF)
backups/        # older versions of the page
```
